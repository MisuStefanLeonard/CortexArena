# GitHub Issue Templates

This directory contains templates for bug reports and feature requests.

## Creating an Issue

1. Go to [Issues](../../issues)
2. Click "New Issue"
3. Choose a template
4. Fill in the required information

---

## Bug Report Template

**Title**: [BUG] Brief description

**Description**:
- What happened?
- What did you expect to happen?
- How can it be reproduced?

**Environment**:
- OS: [Windows/macOS/Linux]
- Python version: [3.13+]
- Django version: [5.2.7]
- Browser: [Chrome/Firefox/Safari]

**Steps to Reproduce**:
1. Go to...
2. Click...
3. See error...

**Expected Behavior**:
What should happen instead?

**Actual Behavior**:
What actually happened?

**Screenshots**:
If applicable, add screenshots

**Error Logs**:
```
Paste any error messages
```

**Additional Context**:
Any other information that might be helpful

---

## Feature Request Template

**Title**: [FEATURE] Brief description

**Description**:
Clear description of the feature and why it's needed.

**Is your feature request related to a problem?**
Describe the problem you're trying to solve.

**Describe the solution you'd like**:
Clear description of what you want to happen.

**Describe alternatives you've considered**:
Other solutions or features you've considered.

**Additional Context**:
Any other information, screenshots, or examples.

---

## Good Practices

✅ **DO**:
- Search existing issues first
- Be specific and descriptive
- Include reproducible steps
- Attach relevant screenshots
- Use code blocks for errors
- Be respectful and constructive

❌ **DON'T**:
- Create duplicate issues
- Use unclear titles
- Include multiple unrelated issues
- Be rude or dismissive
- Post in wrong repository

---

## Labels

Issues are categorized with labels:

| Label | Meaning |
|-------|---------|
| `bug` | Something is broken |
| `enhancement` | Feature or improvement |
| `documentation` | Docs need updating |
| `good-first-issue` | Good for newcomers |
| `help-wanted` | Need community help |
| `question` | Question about usage |
| `wontfix` | Won't be worked on |
| `duplicate` | Already reported |
| `invalid` | Not valid issue |

---

## Priority Levels

- 🔴 **Critical**: Game breaking, data loss
- 🟠 **High**: Major feature not working
- 🟡 **Medium**: Minor bugs, small features
- 🟢 **Low**: Nice to have, polish items

---

## Response Times

- Critical: 24 hours
- High: 2-3 days
- Medium: 1 week
- Low: As time permits
